# 🤖 Discord Бот Экономики и Выплат — Кампания Fazenn 2026

Этот бот реализует предвыборное обещание кандидата **Fazenn**:
- **Автоматические выплаты зарплат каждые 24 часа** по 11 уровням актива:
  - `@[act+10]` — Превосходный Актив (1000 LC / день)
  - `@[act+9]` — Крайне Высокий Актив (800 LC / день)
  - `@[act+8]` — Очень Хороший Актив (650 LC / день)
  - `@[act+7]` — Отличный Актив (500 LC / день)
  - `@[act+6]` — Высокий Актив (400 LC / день)
  - `@[act+5]` — Хороший Актив (300 LC / день)
  - `@[act+4]` — Нормальный Актив (200 LC / день)
  - `@[act+3]` — Не особый Актив (120 LC / день)
  - `@[act+2]` — Низкий Актив (70 LC / день)
  - `@[act+1]` — Ужасный Актив (30 LC / день)
  - `@[act-0]` — Мертв (0 LC)
- **Синхронизация с сайтом Upgrader**: участники могут крутить монеты на сайте, а выигрыши и проигрыши моментально отражаются в боте.

---

## 🚀 Быстрый запуск

1. Перейдите в папку бота:
   ```bash
   cd discord-bot
   npm install
   ```

2. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```

3. Вставьте ваши ключи в `.env`:
   - `DISCORD_BOT_TOKEN` — токен бота из [Discord Developer Portal](https://discord.com/developers/applications)
   - `DISCORD_CLIENT_ID` — Application ID бота
   - `UPGRADER_WEBSITE_URL` — ссылка на ваш задеплоенный сайт на Vercel

4. Запустите бота:
   ```bash
   npm start
   ```

## 🕹️ Доступные слэш-команды

- `/balance` — Проверить свой баланс монет
- `/daily` — Забрать суточный бонус
- `/roles` — Посмотреть тарифную сетку всех 11 ролей и зарплат
- `/upgrader` — Получить интерактивную кнопку-ссылку на сайт Upgrader
- `/pay [пользователь] [сумма]` — Перевести монеты другу
- `/leaderboard` — Рейтинг самых богатых участников группы
